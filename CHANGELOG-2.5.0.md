# ChromeOS Efficiency Updates 2.5.0

## Advanced customisation
- Added dashboard visibility controls for Tools, Sessions, Quick note and Tasks. Hiding a section never deletes its stored data.
- Added custom primary and secondary accent colours that work alongside the existing theme and wallpaper selection.
- Added small, default and large text settings, compact or comfortable dashboard spacing, and a higher-contrast mode.
- Customisation preferences are stored locally and included in validated backup/restore data.

## Compatibility and verification
- Preserved Manifest V3 and minimum Chrome 103.
- No new permissions or background polling were added.
- Static syntax and manifest checks are required before release; ChromeOS runtime testing remains necessary.
