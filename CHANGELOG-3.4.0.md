# 3.4.0 — Remote Mini-app Marketplace

- Added a GitHub-hosted metadata catalogue and static marketplace storefront.
- Added six separately hosted web mini-apps: Research Library, PDF Reader, Citation Manager, Focus Timer, Markdown Editor and JSON Studio.
- Remote app code runs only as ordinary web pages in separate tabs; no remote JavaScript is executed in the extension context.
- Added app install records, pinned versions, favourites, uninstall and user-reviewed updates.
- Added Conservative / Balanced / Unrestricted resource profiles and transparent RAM/CPU estimates.
- Documented data separation, package size versus install-record size, resource estimate methodology and GitHub Pages publishing.
- No new extension permissions, dependencies, frameworks or background jobs.
