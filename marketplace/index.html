HOW INSTALLATION WORKS

Install from inside My Launcher.

This website is the public discovery catalogue. To install and run an app offline, open the Mini-app Store inside the My Launcher extension. Install enables first-party code bundled with your extension; it does not execute downloaded website scripts.

  1. Open a new tab with My Launcher.
  2. Choose Mini-apps in the sidebar.
  3. Select an app and choose Install.
  4. Open it in its own restricted workspace.
