Scope and limitations

  • Checks are non-destructive and do not write test data into extension storage.
  • Memory information is browser-reported device-wide memory, not memory attributable to this extension.
  • Network/provider credentials are not tested and never included in the report.
  • Source-contract checks do not replace clicking through all mini-apps or testing on the Chromebook.
  • Some local resources are checked by fetching the page's referenced scripts and styles; this is not a complete runtime test.
