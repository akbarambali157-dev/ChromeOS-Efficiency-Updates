How do I get the log files?

Claude Code saves each session as a .jsonl file in ~/.claude/projects on the machine it runs on. In your Codespace terminal, copy them into the workspace so you can download them:

mkdir -p claude-logs && cp -r ~/.claude/projects/* claude-logs/
echo "claude-logs/" >> .gitignore

In the file explorer, right-click the claude-logs folder and choose Download, then pick it here. Delete the folder afterwards. The logs contain your prompts and code, so never commit them.

Totals are what Claude Code logged. Brewkeg may count cached tokens differently, so use its Requests page for billing.
